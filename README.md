# CodeAlpha Task 3 - Data Visualization

## 📊 Project Overview

This project was completed as part of the **CodeAlpha Internship – Task 3: Data Visualization**.

The objective of this project is to analyze the **Superstore dataset** and create meaningful visualizations to identify sales, profit, category, regional, and monthly trends.

## 🎯 Objectives

- Analyze sales and profit data.
- Compare sales across different product categories.
- Analyze profit by category.
- Compare sales across different regions.
- Identify monthly sales trends.
- Present insights using clear and colorful visualizations.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook
